### What I Learned

#### Networking Concepts

I developed a stronger understanding of how computer networks operate and how devices communicate with one another. I reviewed important concepts such as IP addresses, MAC addresses, packets, frames, ports, protocols, network devices, and the different layers involved in network communication.

I also reinforced my understanding of the OSI and TCP/IP models. These models provide a useful way to understand where different networking technologies and protocols operate and can help when troubleshooting network or security problems.

#### Networking Essentials

I studied the essential components that allow devices to communicate across local and external networks. This included concepts such as routing, switching, addressing, subnetting, DNS, DHCP, and the role of routers and switches.

I learned that understanding normal network behaviour is important in cybersecurity because identifying suspicious activity requires knowing what legitimate communication should look like.

#### Networking Core Protocols

I explored several protocols that are fundamental to network communication, including TCP, UDP, DNS, DHCP, ARP, and ICMP.

I learned the differences between TCP and UDP and why different applications choose one transport protocol over another. I also developed a better understanding of how DNS resolves domain names, how DHCP provides network configuration to devices, how ARP helps devices communicate on local networks, and how ICMP can be used for network diagnostics.

#### Networking Secure Protocols

I studied how secure protocols protect information transmitted across networks. This included understanding why encrypted alternatives should be preferred when sensitive information is being transmitted.

Examples included HTTPS for secure web communication, SSH for secure remote administration, and other encrypted protocols designed to protect authentication credentials and network traffic.

A key takeaway was that encryption protects data in transit and reduces the risk of credentials or sensitive information being exposed through network interception.

#### Wireshark Basics

I gained hands-on experience using Wireshark to capture and inspect network packets.

I practised examining packet information and using filters to focus on specific types of traffic. This helped me understand how network protocols appear in real network captures rather than only studying them theoretically.

Wireshark demonstrated how packet analysis can support troubleshooting, security monitoring, and investigations by providing detailed visibility into network communication.

#### tcpdump Basics

I learned how tcpdump can be used from the command line to capture and inspect network traffic.

Working with tcpdump helped me become more comfortable analysing network activity without relying on a graphical interface. I practised identifying interfaces, capturing packets, applying filters, and reviewing traffic relevant to an investigation.

I can see how tcpdump would be particularly useful when working with Linux servers or remote systems where a graphical tool such as Wireshark may not be available.

#### Nmap Basics

I was introduced to Nmap as a network discovery and security assessment tool.

I practised using Nmap in authorized lab environments to identify hosts, open ports, and services running on systems. I also learned how scan results can help a security analyst understand a system's exposed network services and identify areas that may require further investigation.

This reinforced the importance of ports and services in network security and showed how network enumeration can contribute to both defensive security assessments and authorized penetration testing.

### Hands-On Practice

During the TryHackMe labs, I practised analysing network communication and using common cybersecurity networking tools.

My practical activities included:

- Inspecting network packets with Wireshark

- Capturing and filtering network traffic with tcpdump
- Identifying hosts and network services using Nmap
- Reviewing open ports and considering the services associated with them
- Examining how common protocols operate across a network

These exercises helped connect networking theory with practical cybersecurity tasks.

### Challenges

One of the main challenges was remembering how the different protocols, ports, network layers, and tools relate to each other. Networking contains many interconnected concepts, so understanding the overall communication process is more useful than simply memorizing individual definitions.

Packet analysis also required careful attention because network captures can contain a large amount of information. Learning how to filter traffic effectively made the analysis more manageable.

I would like to continue practising Wireshark, tcpdump, and Nmap so that using these tools becomes more natural.

### Key Takeaways

My biggest takeaway this week is that networking knowledge is fundamental to cybersecurity. Security analysts need to understand how systems normally communicate before they can effectively identify suspicious network behaviour.

I also learned that Wireshark, tcpdump, and Nmap provide different but complementary capabilities:

- **Wireshark** provides detailed graphical packet analysis.
- **tcpdump** provides lightweight command-line packet capture and analysis.
- **Nmap** helps discover hosts, ports, and network services.

Understanding protocols such as TCP, UDP, DNS, DHCP, ARP, ICMP, HTTP/HTTPS, and SSH gives me a stronger foundation for future topics such as network attacks, intrusion detection, SIEM analysis, vulnerability assessment, and incident response.
